# C# 功能与发行验收

对照基线：当前 `static/` Windows 网页版。禁止把 macOS 专属的外部进程认领、任意 PID 结束接口重新开放。

## 交付顺序

1. 补齐客户端缺失操作，复用现有后台接口；保持隐藏时停止界面轮询。
2. 将 C#、标准库后台与锚点接入当前用户安装器；验证旧版升级、卸载保留数据、开机自启。
3. 接入个人 Fork 的更新检查：兼容的声明式资源可热更新；程序或后台代码变更通过校验后的安装包更新，不远程执行脚本。
4. 运行测试、隐私与许可检查，核对提交身份，发布源码与安装包至个人 Fork，核对 Release 下载文件。

## 已完成证据

- 2026-11-11 三轮性能对比见 `RESOURCE_COMPARISON_2026-11-11.md`。客户端内存和隐藏待机以 C# 更低，前台 CPU 以 HTML 更低；不含共用后台、GPU、受管项目和低配电脑。
- 现有测试覆盖断线恢复、写操作不重放、只清理自有后台、真实 IPv4/IPv6 夹具强停及 WPF 输入框。
- 公开 Fork 为 `BigWai1312/local-ops-windows`；本次读取未发现已发布 Release，更新界面必须处理首次发行的 404。

## 发布限制

2026-11-12 更新测试通过，覆盖 404、摘要不符、取消下载、跨站重定向拒绝和坏资源缓存回退。隔离安装验证包含真实快捷方式、专用 HKCU 测试键、从 PATH 移除 Python 后运行冻结锚点、任务退出码 0/130/7、后台重启后核验实际可执行路径及配置保留、后台停止、重装保留配置及关闭的自启偏好、卸载保留数据。没有替换本机原安装。跨版本切换与失败回滚目前使用合成 payload 测试，不能等同于旧版实际安装的升级验收。

真实卸载测试发现并修复 PowerShell 在 `DETACHED_PROCESS | CREATE_NO_WINDOW` 下未执行清理的问题，已加入真实目录删除回归测试。原生窗口经单实例唤醒与置前后恢复验收，已观察深浅主题切换、设置导航及命令面板打开。深色主题下禁用端口按钮的白底已改用现有主题模板，修改后 C# 回归通过，尚未复看实际画面。

用户按 Escape 中断桌面操作后，停止桌面自动化。编辑器、中文命令搜索、宽窄窗口、日志复制/导出、托盘通知、安装版实际窗口、UAC 安全桌面和 Windows 10 实机仍待验收；自动测试不替代这些结果。

尚未通过整套安装、升级、更新、UI 和隐私验收前，不把预览文件当作正式安装包发布。性能报告对应测量时的源码，后续新增功能需重新检查后台待机与前台回归。
