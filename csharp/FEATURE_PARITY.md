# C# 功能与发行验收

对照基线：当前 `static/` Windows 网页版。禁止把 macOS 专属的外部进程认领、任意 PID 结束接口重新开放。

## 交付顺序

1. 补齐客户端缺失操作，复用现有后台接口；保持隐藏时停止界面轮询。
2. 将 C#、标准库后台与锚点接入当前用户安装器；验证旧版升级、卸载保留数据、开机自启。
3. 接入个人 Fork 的更新检查：兼容的声明式资源可热更新；程序或后台代码变更通过校验后的安装包更新，不远程执行脚本。
4. 运行测试、隐私与许可检查，核对提交身份，发布源码与安装包至个人 Fork，核对 Release 下载文件。

## 已完成证据

- 2026-11-12 用户安装候选包后发现历史退出码导致整页解析失败：Windows 无符号退出码可超过 Int32。客户端退出码字段改为 Int64，回归覆盖 null、零、负数、Int32 边界和 UInt32 最大值；修复后的 API 客户端已只读解析本机实际后台数据，未改写历史配置。修复安装包仍需用户覆盖安装后的界面确认。

- 2026-11-11 三轮性能对比见 `RESOURCE_COMPARISON_2026-11-11.md`。客户端内存和隐藏待机以 C# 更低，前台 CPU 以 HTML 更低；不含共用后台、GPU、受管项目和低配电脑。
- 现有测试覆盖断线恢复、写操作不重放、只清理自有后台、真实 IPv4/IPv6 夹具强停及 WPF 输入框。
- 公开 Fork 为 `BigWai1312/local-ops-windows`；本次读取未发现已发布 Release，更新界面必须处理首次发行的 404。
